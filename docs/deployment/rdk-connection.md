# RDK X5 连接信息

## 当前连接方式

- **连接类型**：有线连接
- **SSH 地址**：`root@192.168.128.10`
- **认证方式**：免密登录（已配置 SSH 密钥）

## 常用操作

```bash
# 登录 RDK
ssh root@192.168.128.10

# 复制文件到 RDK
scp <本地文件> root@192.168.128.10:<远程路径>

# 从 RDK 复制文件
scp root@192.168.128.10:<远程路径> <本地路径>
```

## 注意事项

- 该 IP 为当前有线网络环境下的固定地址，若更换网络环境需重新确认。
- 后续部署脚本、同步脚本可硬编码此地址，但需在文档中注明变更入口。
