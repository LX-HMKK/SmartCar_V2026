# RDK X5 连接信息

## 当前连接方式

- **连接类型**：无线连接
- **SSH 地址**：`root@172.16.25.27`
- **有线备用地址**：`root@192.168.128.10`
- **认证方式**：免密登录（已配置 SSH 密钥）

## 常用操作

```bash
# 登录 RDK
ssh root@172.16.25.27

# 复制文件到 RDK
scp <本地文件> root@172.16.25.27:<远程路径>

# 从 RDK 复制文件
scp root@172.16.25.27:<远程路径> <本地路径>
```

## 注意事项

- 无线地址随现场网络环境可能变化，变更后同步更新本文件、`AGENTS.md`、README 和部署手册。
- 有线直连时使用备用地址 `192.168.128.10`。
